# 课程目录与学习入口设计

## 目标

课程目录负责“发现课程”，我的学习负责“消费已获得的课程权益”。本批形成以下闭环：

> 登录用户浏览课程广场 → 按分类或关键词查找课程 → 查看安全章节目录 → 已有权益继续学习，否则进入拼团活动。

课程目录不返回视频地址。完整章节播放接口在服务端再次校验当前用户的有效课程权益，不能依赖前端按钮隐藏实现授权。

## 数据模型

- `course_category`：课程分类，包含稳定 ID、名称、排序和启停状态。
- `course.category_id`：课程归属一个分类；历史课程迁移至 `general`，演示 Java 课程归入 `backend`。
- 课程列表聚合已发布章节数量与总时长，不创建重复统计表。
- 权益状态通过与课程目录同一次 SQL 的 `EXISTS` 子查询得出，避免分页后逐条查询形成 N+1。

## 接口

| 接口 | 用途 | 返回边界 |
|---|---|---|
| `GET /api/learning/catalog/categories` | 可用分类 | ID、名称 |
| `GET /api/learning/catalog/courses` | 关键词、分类、有界分页 | 课程摘要、聚合章节信息、本人权益状态 |
| `GET /api/learning/catalog/courses/{courseId}` | 课程详情 | 课程摘要与安全章节目录，不含视频 ID/地址 |
| `GET /api/learning/courses/{courseId}/chapters` | 学习空间 | 仅有效权益用户可用，返回播放所需信息 |

分页页大小最大 50。分类必须存在且启用；只展示已发布课程和已发布章节。

## 前端结构

- `/courses`：课程广场，真实分类、关键词搜索、分页和权益标签。
- `/courses/:courseId`：课程介绍和章节目录。
- 已有权益显示“继续学习”，跳转 `/learning/courses/:courseId`。
- 未有权益显示“查看拼团活动”，不伪造单买、试听或开团能力。
- `CourseCatalogContext` 和 `CourseCatalogStore` 统一承载状态与动作；分类及首屏课程并发请求，路由卸载或后续查询会令旧响应失效。
