# 技术笔记流 UI 调整

属于第 5.6 轮前端展示增量，保留现有接口和分页。

- 按接口顺序逐张放入当前最短列，同高时从左往右；DOM 与键盘顺序保持接口顺序。
- 容器宽度决定 1—4 列，间距 20px。ResizeObserver 在图片、作者信息和容器尺寸变化后重新布局，卸载时清理。
- 预览优先使用正文首张站内图片（4:3 裁切），其次围栏代码（3—8 行高度），否则文字摘要（3—6 行高度）。标题最多两行。
- 卡片展示预览、标题、类型及最多三个技术标签、作者时间、互动统计。详情标签不再受卡片截断规则影响。
- 图片复用现有授权读取能力；授权失败显示错误占位。当前解析覆盖编辑器生成的 Markdown 内联图片及围栏代码。
