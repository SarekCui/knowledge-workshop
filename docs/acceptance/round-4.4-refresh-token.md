# 第 4.4 轮验收记录：刷新令牌轮换与注销

- 验收日期：2026-09-08
- 环境：Java 17、Spring Boot 3.5.9、MySQL 8.4 Testcontainer

## 实现范围

- 登录返回 30 分钟 JWT 访问令牌和 30 天不透明刷新令牌。
- 数据库仅保存刷新令牌 SHA-256 摘要、状态、令牌族与替代关系。
- `/api/iam/auth/refresh` 使用行锁串行化同一令牌的轮换。
- 已轮换令牌被重用时撤销整个令牌族。
- `/api/iam/auth/logout` 撤销令牌族并支持幂等重试。

## 备注

注销后已签发的访问令牌仍可使用到过期，当前上界为 30 分钟。这是避免网关和每个业务服务逐请求回查 IAM 的明确取舍，不宣称访问令牌可即时撤销。
