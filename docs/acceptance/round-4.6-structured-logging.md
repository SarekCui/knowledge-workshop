# 第 4.6 轮验收记录：结构化日志

- 验收日期：2026-09-08
- 环境：Java 17、Spring Boot 3.5.9、Logback、Spring Cloud Gateway

## 实现范围

- IAM、营销、积分与网关统一输出 Logstash JSON 控制台日志。
- 每条日志固定补充 `service` 字段。
- Servlet 服务通过 MDC 关联 `requestId`，请求结束后恢复原 MDC，避免线程复用造成上下文泄漏。
- Gateway 使用显式结构化字段记录响应式请求完成事件，不依赖跨线程 MDC。
- HTTP 日志包含方法、路径、状态码和耗时，不记录请求体、查询参数或认证凭证。
