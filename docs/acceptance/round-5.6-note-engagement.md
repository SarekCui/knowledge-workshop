# 5.6 Note互动验收

日期：2026-09-15。

## 已交付

- V5迁移新增点赞、收藏、评论事实表，以及Note点赞数、收藏数和评论数冗余字段与热门索引。
- 点赞/收藏以`(note_id,user_id)`唯一关系幂等；先锁Note行、再检查并写事实、最后调整计数，避免依赖MySQL受连接选项影响的affected rows语义。
- 评论使用`(user_id,client_request_id)`幂等并校验请求指纹，支持一级回复、作者删除、版本冲突及有回复父评论删除保护。
- 公开列表支持LATEST/HOT；HOT按收藏、点赞、评论、发布时间和ID倒序，全部来自真实互动事实。
- React接入发现页排序、详情点赞/收藏/评论、我的点赞和我的收藏；共享状态与操作由独立Context/Store承载，详情互动状态和评论首屏并行请求。
- 评论未知结果锁定原内容和UUID供重试，明确400后才允许修正内容并生成新UUID。

## 2026-09-17 互动按钮视觉增量

- 详情页点赞改为“心形 + 数字”，选中使用红色实心状态；收藏改为“星形 + 数字”，选中使用金色实心状态。取消选择后恢复空心图标与中性色。
- 发现页卡片的点赞、收藏和评论统计统一使用图标加数字；图标保留中文可访问名称。
- 点赞和收藏继续使用原有乐观更新、单操作互斥与失败回滚，不修改API、幂等或事务语义。
- `npm test`：26个前端测试文件、102个测试通过；`npm run build`：TypeScript检查与Vite生产构建通过。
- 真实浏览器复验已有互动笔记：取消及恢复点赞、取消及恢复收藏后，数字和图标状态同步，最终恢复原始事实；选中点赞色为`rgb(225, 29, 72)`，收藏色为`rgb(217, 119, 6)`。
- 笔记卡片点击后使用独立详情路由，不再通过背景路由展示阅读弹窗；浏览器返回仍回到列表。
- 详情页点赞、收藏和评论统一为58×40像素无边框点击区；悬停和激活均不显示按钮底色，仅心形/星形本身以实心及对应颜色体现状态，收藏选中色为较浅的`#e9a23b`。
- 公开笔记列表接口返回当前账号的点赞/收藏状态；详情页互动采用乐观更新并同步到列表卡片，返回列表即可看到实心心形/星形与最新计数。
- 游客无需登录即可浏览课程广场、课程详情、公开笔记列表、笔记详情与评论；点赞、收藏、评论及个人内容在操作时引导登录。个人入口统一收进头像下拉菜单。
- 评论按一级评论组织线程，回复缩进显示在父评论下方并使用左侧层级线；回复标题只显示回复者头像，被回复者改为`@用户名`文本，避免重复头像造成关系误读。
- 评论分组函数新增父子归组与分页父评论缺席的回退测试；真实含回复笔记已通过浏览器视觉复验。

## 明确边界

- 本轮没有图片上传、内容举报审核、热度反作弊或推荐算法。
- 浏览器验收评论保留为本地真实测试数据；未在未确认的情况下执行删除操作。
- Vite生产主包约1.2MB，后续应做路由级动态导入与依赖分包，并以首屏性能数据验收。
