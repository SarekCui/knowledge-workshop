# 第 5.6 轮：月度签到日历

- 日期：2026-09-14。
- 范围：本人月度签到查询、日历轨迹、切月、本月返回、签到后刷新；不支持补签，不修改积分发放规则。

## 设计

- 新增 `GET /api/points/sign-ins?month=YYYY-MM`，用户身份只来自 UserContext，不接收外部 userId。
- 返回 `month / today / signedDates`；today为服务端UTC日期，日期升序。数据库事实源按用户及月份过滤，依赖既有用户/日期唯一索引，每月最多31条。不依赖Bitmap恢复历史，不新增缓存。
- 年份0001—9999、月份01—12；非法输入400，未登录401。按原有BO/VO/Converter分层。
- PointsContext承载月度状态和方法，SignInCalendar独立展示；已签绿色、今日蓝色边框、未来置灰。查询失败显示错误与重试，不把未知日期误标为未签。
- 切月清除旧轨迹并忽略旧响应；签到成功后并行刷新日历与榜单，两者读取失败不撤销签到结果。
- 遵循React最佳实践：月份格子、已签集合直接从月查询派生，不在Effect里额外同步冗余状态；未增加日期依赖或Demo数据。
