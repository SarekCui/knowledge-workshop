# ADR-0012：Note知识分享增量

日期：2026-09-14；状态：采纳。

## 决策

沿用learning.note传统分层及独立note表，课程关联改为可选，不新增服务或同步依赖。后续社区规模与独立变更达到拆分条件再评估迁移，禁止双写两套文章/笔记。

状态为DRAFT、PRIVATE、PUBLIC。历史记录迁移为PRIVATE，新建默认为DRAFT；状态只能由所有者显式版本化切换。PUBLIC正文及标题不可直接修改，先转DRAFT或PRIVATE再编辑，避免自动公开未确认的修改。发布要求非空正文。撤回、删除后不再进入公开查询。

管理接口维持登录及所有者权限；新增公开范围查询接口仍沿用当前网关登录要求，“公开”指其他登录用户可浏览，并非本轮开放匿名网关。不允许公开接口回退到所有者查询。单条不可见一律404避免泄露私人存在性。

创建courseId可空；有课程须为已发布课程，有章节须属于该课程。仅视频时间点要求有效学习权益；不公开课程播放URL。保留clientRequestId幂等与乐观锁，无关联比较须空值安全。

第一批MySQL参数化标题/正文包含搜索、有界分页与确定性时间/ID排序；不部署搜索引擎。第三批的点赞、收藏和评论事实仍归属learning.note域，使用MySQL唯一约束与同库事务维护冗余计数；热门只按真实互动计数确定性排序，不将最新伪装成热门。私人数据不写入公开列表、搜索或推荐。

点赞、收藏写接口以用户与笔记组成的自然业务键幂等，评论创建以客户端UUID幂等并绑定请求指纹。互动写入先锁定PUBLIC笔记行，再写事实表和调整非负计数，以固定锁顺序避免并发撤回、重复操作造成计数漂移。首版不引入Redis互动缓存；事实规模证明需要时再单独决策缓存、对账与反作弊。

## 后续边界

用户资料展示、图片存储/上传、审核举报与热度反作弊后置。公开创作与互动仅适用于本地受控演示；没有审核治理不宣称可直接面向互联网生产开放。
